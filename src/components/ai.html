CrewOS / Tenant-aware LLM workflows

From model calls to managed execution.

CrewOS executes a fixed two-step LLM workflow through a FastAPI and Celery service. It combines tenant authentication, task-ownership checks, bounded inference retries, and an OpenAI-compatible model adapter, with Ollama as a local inference option.

LLM workflowsOllamaCeleryRedis task ownershipKubernetes

The architecture separates domain logic from LLM adapters and infrastructure. It makes tenant context and workload routing explicit, so the AI integration can be inspected as a system.

Capabilities demonstrated

Two-step LLM workflows · Model endpoint integration · Tenant authentication · Asynchronous execution · Owned-result access · Bounded inference retries

Architecture questions to take further

Tool-using agent loops, persistent memory, durable checkpoints, approvals, and multi-agent evaluation remain planned. Current verification demonstrates workflow delivery and context forwarding, not real-model reasoning quality.
